## 🔧 Configuração no GitHub

1. Vá para: https://github.com/VidiPT89/ListOfMovies
2. Clique em **⚙️ Settings** (Engrenagem no topo direito da página do repo)
3. Procure a seção **"About"** no lado direito
4. Edite a **Description** com o texto acima
5. Adicione os **Topics** (etiquetas) abaixo da description

## 📋 MIT License

A licença MIT já está no README. Para adicionar ao GitHub:

1. Vá para **Settings** → **License**
2. Escolha **MIT License** da lista dropdown
3. Ou manualmente, crie um arquivo `LICENSE` na raiz com o conteúdo MIT

Exemplo de LICENSE MIT (já pode estar criado):
```
MIT License

Copyright (c) 2026 David Arsénio Martins
```
